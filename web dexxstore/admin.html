เมนูการจัดการ

คลังสินค้า (Manage Products)

แก้ไขชื่อ ราคา รูปภาพ รายละเอียด และแพ็กเกจสินค้า

รูปภาพ ชื่อสินค้า & หมวดหมู่ ราคา ป้ายกำกับ จัดการ

ตั้งค่าข้อมูลหน้าเว็บ & Hero

แก้ไขหัวข้อหลัก คำบรรยาย ลิงก์ Discord และตัวเลขสถิติ

แถบประกาศวิ่ง (Marquee Ticker)

เพิ่ม/ลบ ข้อความประกาศวิ่งที่พาดผ่านกลางหน้าเว็บ

จัดการรีวิวลูกค้า (Reviews)

เพิ่ม ลบ หรือแก้ไขข้อความรีวิวและชื่อผู้ใช้

คำถามที่พบบ่อย (FAQs)

เพิ่มหรือแก้ไขคำถาม-คำตอบที่แสดงบนหน้าเว็บ

สำรอง & จัดการฐานข้อมูล (Database)

ข้อมูลทั้งหมดถูกบันทึกและรันบนเครื่องของคุณอย่างปลอดภัย

ส่งออกข้อมูล JSON

ดาวน์โหลดการตั้งค่าและรายการสินค้าทั้งหมดเก็บไว้สำรอง

นำเข้าข้อมูล JSON

อัปโหลดไฟล์ JSON ที่สำรองไว้เพื่อกู้คืนข้อมูล

รีเซ็ตเป็นค่าเริ่มต้น

ล้างการแก้ไขทั้งหมดและนำข้อมูลออริจินัลของ DEXXSTORE กลับมา

จัดการสิทธิ์แอดมิน (Admin Discord IDs)

กำหนด Discord User ID ที่ได้รับสิทธิ์เข้าถึงแผงควบคุมหลังบ้าน DEXXSTORE

วิธีดู Discord User ID: ใน Discord ไปที่ Settings -> Advanced -> เปิด Developer Mode -> คลิกขวาที่ชื่อโปรไฟล์แล้วกด "Copy User ID"

รายชื่อ Discord ID ที่ได้รับสิทธิ์ Admin ปัจจุบัน Real-time Permissions
